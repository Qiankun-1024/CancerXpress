# CancerXpress TCGA归因与分子程序分析结果包 v1.0.0

## 这份数据是什么
本包按实际分析顺序整理TCGA患者的功能轴风险贡献、主导轴基因归因、NMF程序、功能富集及补充证据。每个步骤的README介绍问题、输入来源、计算方法、图示含义和解释限制；数据、现有图片和相关历史实现放在同一步骤内。文件不是按PDF/表格/脚本统一分仓。

## 推荐阅读顺序
1. [功能轴风险状态与5A](01_risk_states/README.md)：患者为何被分到C01–C14。
2. [主导轴基因风险归因](02_gene_attribution/README.md)：基因矩阵从什么模型量分配得到，以及怎样质控。
3. [NMF程序与5B](03_nmf_programs/README.md)：不同风险状态内部的替代基因贡献模式。
4. [程序富集与5C](04_program_enrichment/README.md)：数据库、方向、NES、FDR及代表条目的解释。
5. [跨轴免疫leading-edge对照](05_immune_overlap/README.md)：免疫主题是否使用相同基因。
6. [条件稳定性及表达支持](06_stability/README.md)：泛癌bootstrap和BRCA表达子集各提供什么证据。
7. [冻结模型参考特征](07_reference_features/README.md)：供新样本查询的latent/ME，不替代历史OOF结果。

## 四个不能混淆的量
- ME值：模型预测的功能轴表征。
- 轴Shapley贡献：相对于模型参考状态，该轴对预测风险的贡献。
- 基因风险归因：经指定轴分配到基因的风险贡献，不是表达量。
- NMF usage / loading：患者使用程序的权重，以及程序的基因组成，分别对应W、H。

基因集归因富集、真实表达推断的TF活性和临床生存关联也是三类不同证据。程序“富集ESR1靶基因”不自动意味着ESR1活性最高；H−富集不意味着表达抑制；多数据库结果不能视为独立重复实验。

## 实际交付范围
本包不等于完整论文所有中间结果，也不是从零训练的完整流水线。包含的历史脚本用于追溯实现，仍可能依赖原项目路径、基因集、检查点及中间文件。模型、原始表达和五万多样本数据库单独发布；本包未纳入的中间材料会在相关步骤说明。OS患者级结局未随主样本表公开。

所有样本表应按sample_id连接；NPY必须依据对应行序/列序表读取。程序编号只在本cluster有效。基因矩阵中的NaN是计算/质控无效，不能替换成生物学零。正式比较前核对模型版本、预处理、基线、癌种范围与基因候选集。

## 溯源、完整性和公开发布
`provenance.json`记录交付文件与原项目来源；`manifest.json`给出文件大小和SHA-256。外层压缩包配套SHA-256校验文件。`METHODS_original_export.md`保留早期英文导出说明，当前目录与解释以各步骤中文README为准。

公开上传前需确认原始数据与第三方基因集再分发权限。本包仅供科研，不是临床诊断工具。不要将整理包里的模型风险数值作为临床决策依据。
