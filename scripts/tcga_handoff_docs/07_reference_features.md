# 第七步：用于新样本查询的冻结模型参考特征

## 与历史研究结果的区别
本步骤重新使用发布模型和对应预处理资源，为本包9,579例TCGA样本计算latent和八个ME。这是面向软件查询/对照的固定模型参考，不是第一步五折风险模型产生的历史OOF风险归因。不要将两个版本的ME或潜在特征按名称相同就混合。

## 输入和计算
使用相同样本原始TPM及模型对应的基因ID、像素映射和归一化资源。调用`CancerXpress.encode_features()`：先得到ME模型encoder的潜在均值表示，再经其ME预测头输出八轴值；这里未对参考样本额外做域适配。参考特征与`model_signature`绑定，签名由模型及关键预处理文件指纹组成。

## 文件结构和读取
`reference_atlas/samples.tsv`为样本元数据；`features.npz`含latent与me矩阵；`atlas.json`记录格式、特征名及模型签名。行序按保存的元数据对应，推荐通过包加载，不自行拼接不同文件版本。

```python
from cancerxpress import ReferenceAtlas
atlas = ReferenceAtlas.load('07_reference_features/reference_atlas')
```

本步骤没有单独图片；它用于后续查询，而不是作为Figure 5A的图源。完整五万多参考数据库是另一份发布，本目录只是TCGA归因样本对应的参考特征。

## 新样本如何使用
通过同版本CancerXpress和TPM预处理计算新样本特征，再选择latent或ME空间查询。当前接口支持余弦或欧氏距离；启用标准化时只用参考集均值/标准差。余弦相似度和欧氏距离不是同一尺度；相近不等于癌种相同、风险相同或临床等价。若限制同癌种检索，需正确提供癌种元数据。

域适配应单独记录训练/验证/测试患者和生物学分层；参与适配的患者不能再无条件称为独立外部验证。匹配到某个TCGA患者不自动赋予其cluster或NMF程序，状态映射和冻结程序投影是额外分析。

## 缺失内容与可复现条件
本目录不包含模型权重或原始表达。需从模型发布和相应数据发布取得同版本输入，并通过模型签名检查。研究型历史归因的fold基线不能由此参考矩阵替代；若要重新计算历史归因，应回到第二步的实现与训练折资源。
